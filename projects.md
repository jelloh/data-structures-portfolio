## Project 1: Recursive Structure Engine

For this project, I focused on creating a text compressor that utilizes a Binary Tree. The Nodes are used to represent chunks of a compressed message, and contain binary versions of the associated characters. The BinaryTree keeps track of each chunk, and the subchunks made by splitting the text further and further. Leaf nodes only contain one character in the entire message. Lastly, I added the ability to get a specific node's chunk text and a post-order traversal of the nodes that shows how the message is split among all the nodes.
